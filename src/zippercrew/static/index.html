Pair Programming

Human shares the task with both roles. Implementer works in the repository and passes a proposal to Reviewer. Reviewer inspects the files and returns APPROVE or REVISE with findings.

Your involvement mode determines who decides whether to ship or request another round. The full review goes back to the same Implementer conversation.

Pair Programming is the available process in this version. Executed by ZipperGen.
