Linked Studio · implementation handoff

This is a runnable Phaser design integration, prepared beside the existing app. The app’s active renderer and backend have not been changed.

Included assets

  • Room background: 1836 × 857, cleaned from the approved three-participant Linked Studio. Display only the top 711 pixels; the existing concept caption stays outside the scene.
  • RGBA cast atlas: 1774 × 887. Human neutral and orchestrating poses; Implementer maker pose; Reviewer checking pose. Frame definitions work with Phaser’s atlas loader.
  • Scene layout: foot anchors, display heights, furniture occlusion polygons and message rules.
  • Phaser scene: working composition, pose switch, separate activity bubbles and message preview.

Host integration

  1. Copy the two PNGs and atlas JSON to a versioned app asset directory. Update the scene’s three preload URLs to that directory.
  2. Load the scene specification before the scene class. The preview uses the app’s existing vendored Phaser 3.90.0.
  3. Keep participant IDs separate from role and visual frame. Connect the participant’s observable work state to its activity bubble.
  4. Pass authoritative protocol events to showProtocol({id,type,from,to}). The demo button is sample-only. Rendering and tween completion must never acknowledge a message, advance the run, or synthesize protocol events.
  5. Retain the sprite sizes when adding linked rooms. On narrow displays, pan the stage instead of squeezing it below legible size. The preview maintains a 960-pixel minimum stage width.

Layer order

Background → characters → masked table/laptop foreground → local activity bubbles → travelling protocol cards. Labels sit below the room. Sprite origins are bottom-center and positions refer to the feet.

The foreground is a masked second copy of the same room texture, so furniture edges line up exactly. These masks handle occlusion only. For walking, create separate collision footprints; do not use the mask as a movement mesh.

Asset scope

The agent designs remain the approved rabbit and paper inhabitants. Their atlas cutouts were generated from the locked source, so they are faithful extractions rather than pixel-identical copies. The source reference is unchanged.

This package supplies the static scene and two Human poses, not a complete animation rig. Generated artwork still has slight tonal variation; strict single-color fills, isolated prop textures, and walking frames remain production cleanup. The background preserves the approved room’s existing color treatment.
